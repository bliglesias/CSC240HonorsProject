# CSC240 Honors Project

The same macro tracker prompt given to three AI models, each writing a C (procedural) and a C++ (object-oriented) version.

## How to run

Open a terminal in the model's folder, then compile and run:

**C**
```
gcc filename.c -o filename
./filename
```

**C++**
```
g++ filename.cpp -o filename
./filename
```

For example, in the `Claude` folder:
```
gcc claude_macroTracker_c.c -o claude_macroTracker_c
./claude_macroTracker_c
```

On Windows, run `filename.exe` instead of `./filename`.
